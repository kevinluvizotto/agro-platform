# Agro Platform (Hackathon)

Este repositório centraliza a infraestrutura e documentação da plataforma AgroSolutions IoT.

## Pastas
- `k8s/`: manifests Kubernetes (AKS)
- `docs/`: arquitetura, decisões e runbook de execução
- `.github/workflows/`: pipelines de deploy (GitHub Actions)

## Serviços (microservices)
- agro-identity-api
- agro-properties-api
- agro-telemetry-api
- agro-alerts-api
- agro-portal
